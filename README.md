# Diabetes Prediction Using Machine Learning

## Overview
This project focuses on predicting diabetes risk using machine learning models based on health and lifestyle indicators from the CDC Behavioral Risk Factor Surveillance System (BRFSS).

## Objective
To analyse whether various health factors (such as BMI, physical activity, and lifestyle habits) can be used to accurately predict the presence of diabetes.

## Dataset
The dataset is based on CDC BRFSS 2015 data, accessed via Kaggle. It includes features such as:
- BMI
- Age
- Smoking habits
- Physical activity
- General health indicators

## Approach
- Performed data preprocessing and cleaning
- Conducted exploratory data analysis (EDA)
- Built classification models including:
  - Logistic Regression
  - Decision Tree
- Evaluated models using accuracy and performance metrics

## Results
- Achieved approximately **85% model accuracy**
- Identified key factors influencing diabetes risk

## Key Insights
- Lifestyle-related features such as BMI and physical activity showed strong correlation with diabetes
- Machine learning models can effectively support early risk prediction

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn

## How to Run
1. Download the dataset file:
   `diabetes_binary_health_indicators_BRFSS2015.csv`
2. Open the notebook:
   `diabetes_prediction_ml.ipynb`
3. Run all cells
